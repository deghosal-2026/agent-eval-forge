# agent-eval-forge

**A test lab for AI agents — scenarios, adversarial edge cases, regression suites, and trajectory-level scoring.**

Did the agent actually get better, or did you just change it? agent-eval-forge answers that question with repeatable, scenario-driven evaluation.

## Why

Teams change prompts, tools, and models constantly, then eyeball a few examples and call it progress. That is not engineering.

agent-eval-forge is the eval infrastructure that makes agent improvement measurable.

## Status

Pre-alpha. PRD and architecture in progress.

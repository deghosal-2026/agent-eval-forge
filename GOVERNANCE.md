# Governance

EvalForge is maintained by [deghosal-2026](https://github.com/deghosal-2026). 

## Decision Making

- The maintainer has final decision authority on contributions, releases, and roadmap.
- Community input is valued via GitHub Issues and Discussions.
- Breaking changes are discussed in issues before implementation.

## Releases

- **v0.1.x** — Initial release with core runner, scoring engine, adapters, and field test harness.
- **v0.2.x** — Multi-layer LangGraph validation, VCR/testing profiles, richer reports, expanded field agent roster.
- **v0.3.x** — Advanced features: distributed execution, compliance hooks, public leaderboard.

See `docs/wbs.md` for the full roadmap.
